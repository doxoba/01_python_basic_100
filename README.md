# Codeup 파이썬 기초 100제 풀이

[Codeup](https://codeup.kr) "파이썬 기초 100제"를 풀이한 저장소입니다. 부트캠프 진행 일차(day)별로 폴더를 나누고, 문제 1개당 파일 1개로 관리합니다.

## 폴더 구조

```
01_python_basic_100/
├── _template.py        # 새 문제 풀 때 복사해서 쓰는 템플릿
├── day01/
│   ├── 6001_기초-출력_출력하기01.py
│   ├── 6002_기초-출력_출력하기02.py
│   └── ...
├── day02/
│   └── ...
└── ...
```

- 폴더는 `day01`, `day02`, ... 형식으로 학습 일차별로 구분합니다.
- 각 day 폴더 안에는 그날 푼 문제가 **문제 1개당 파일 1개**로 들어갑니다.
- 예전에는 하루 분량을 파일 1개에 몰아서 작성했지만, 문제별로 찾아보기 쉽도록 파일을 분리했습니다.

## 파일 이름 규칙

```
{문제번호}_{분류}_{제목}.py
```

예: `6009_기초-입출력_문자1개입력받아그대로출력하기.py`

- **문제번호**: Codeup 사이트에 표시된 문제 번호
- **분류**: Codeup에서 제공하는 문제 분류(예: 기초-출력, 기초-입출력)
- **제목**: 문제 제목을 파일명에 쓸 수 있게 축약한 것

## 파일 내부 구조 (`_template.py`)

```python
# ---------------------------------------------------------
# 번호 : [분류] 제목(py)
# ---------------------------------------------------------
# 문제: (여기에 문제 원문을 요약해서 붙여넣기)
# ---------------------------------------------------------
# (여기에 내 풀이)

# 메모: (막힌 점 / 새로 배운 것 - 없으면 생략)
```

새 문제를 풀 때는 `_template.py`를 복사해서 해당 day 폴더에 규칙에 맞는 파일명으로 저장한 뒤, 문제 설명과 풀이, 메모를 채워 넣습니다.

## 문제 파일 자동 생성 (`codeup_new.py`)

파일 생성 → 파일명 지정 → 양식 채우기를 매번 손으로 하지 않도록, Codeup 문제 페이지에서 분류/제목/문제 설명을 긁어와 규칙에 맞는 파일을 자동으로 만들어주는 스크립트입니다.

```
pip install requests beautifulsoup4   # 최초 1회

python codeup_new.py day02 6021              # day02/6021_..._....py 1개 생성
python codeup_new.py day02 6021 6022 6023     # 여러 개 생성
python codeup_new.py day02 6021-6024          # 범위로 생성
python codeup_new.py day02 6021-6024 --open   # 생성 후 VSCode로 바로 열기 (code CLI 필요)
```

- `day` 폴더가 없으면 자동으로 만듭니다.
- 이미 있는 파일은 덮어쓰지 않고 건너뜁니다.
- 문제 설명은 자동으로 채워지지만, 실제 풀이와 메모는 직접 작성해야 합니다.
- 자동 생성된 제목은 원문을 그대로 붙인 형태라 예전 파일명(수동으로 줄인 표현)과 완전히 똑같지는 않을 수 있습니다.
